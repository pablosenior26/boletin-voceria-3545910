# Boletín de Vocería – Ficha 3545910

Boletín web de acompañamiento para los aprendices de la **Ficha 3545910 del Tecnólogo en Análisis y Desarrollo de Software – SENA**.

El proyecto surge desde la vocería de la ficha como una herramienta sencilla para organizar y comunicar información que puede ser útil durante el proceso de formación.

## ¿Para qué sirve?

El boletín busca facilitar el seguimiento de la formación mediante tres componentes principales:

- **Estamos avanzando:** presenta brevemente el momento en el que se encuentra el proceso formativo.
- **Ruta de evidencias:** organiza las evidencias de acuerdo con sus fechas de vencimiento, diferenciando las vencidas, las correspondientes a la semana y las próximas.
- **Oportunidades de la semana:** destaca transferencias y espacios de acompañamiento ofrecidos por el SENA que pueden ser útiles para los aprendices.
- **Desde la vocería:** recuerda los canales de acompañamiento y comunicación disponibles para la ficha.

El boletín no reemplaza la información oficial publicada en **Zajuna**, el cronograma de formación ni las orientaciones de los instructores. Su función es facilitar la organización y el acompañamiento entre aprendices.

## Primera edición

**Semana del 21 al 27 de septiembre de 2026**

Esta primera edición coincide con la transición entre actividades de aprendizaje del componente técnico y organiza algunas de las evidencias y oportunidades relevantes para la semana.

## Tecnologías utilizadas

El boletín fue desarrollado inicialmente con:

- HTML5 para la estructura y el contenido.
- CSS para el diseño visual y la adaptación a dispositivos móviles.
- GitHub para el almacenamiento y control de versiones.
- GitHub Pages para la publicación del sitio web.
